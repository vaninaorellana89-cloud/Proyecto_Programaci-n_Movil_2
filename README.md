# Gestor de gastos personales

Trabajo práctico de Desarrollo Móvil realizado con React Native y Expo.

## Funcionalidades
- Agregar gastos con descripción, monto y categoría.
- Mostrar los gastos registrados.
- Calcular el total gastado.
- Eliminar gastos y actualizar el total.

## Cómo ejecutarlo
1. Instalar Node.js.
2. Descargar el proyecto y abrir su carpeta en VS Code.
3. Ejecutar: npm install
4. Ejecutar: npx expo start
5. Escanear el QR con Expo Go desde el celular.

La computadora y el celular deben estar conectados a la misma red Wi-Fi.

## Datos
Los gastos se guardan temporalmente en la memoria de la aplicación.
No se utiliza una base de datos y no se conservan al reiniciar.
